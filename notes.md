- It should be very clear AI does not automatically apply the plans it recommends. It must be approved by the practitioner who can modify or deny it as they need.

- ElevenLabs is used for accessibility purposes; it speaks aloud so that it can be controlled without requiring the full use of hands and can be spoken aloud to patients. For example, when a patient is ready to undertake exercises, ElevenLabs will ask aloud if the patient is ready and the patient responds with "I'm ready" to start motor exercises (and thereby remove the need to them to come intervene at the screen)

- There needs to be an algorithm that can be used to detect in video camera if a patient has fallen or is in potential danger without mistaking it for harmless scenarios. But in the case of actual harm, a practitioner is quickly alerted via the TigerData database

- Cognitive exercises should aim to be like fun, engaging brain games that improve the impacted cognitive functions of a patient as prescribed by the practitioner.

- Seeded data must be available for the database for demo purposes. In the context of a Docker deployment, a parameter passed (`--seed`) can be set to run the seed on `docker compose up`.

- TigerData is used to quickly update and store patient info and account data, including urgent alerts sent to practitioners like when a patient is in potential danger.
